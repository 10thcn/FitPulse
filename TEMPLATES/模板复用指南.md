# 📋 软工团队作业模板复用指南

## 🚀 快速开始（3 步）

### 1. Fork 本仓库

点击右上角 **Fork** 按钮 → 选择你的 GitHub 账号 → 创建你自己的副本。

### 2. 替换项目信息

```bash
git clone https://github.com/你的账号/FitPulse.git 你的项目名
cd 你的项目名
```

全局替换以下内容：

| 搜索 | 替换为 |
|---|---|
| `FitPulse` | 你的项目名 |
| `power819` | 你的 GitHub 用户名 |
| `健身动作矫正 & 居家锻炼智能 Agent` | 你的项目一句话描述 |

## 📦 模板资产清单

### A. 设计文档模板（docs/ 目录）

基于 **GB/T 8567** 国家标准格式的设计文档模板，可直接填充内容：

| 文档 | 路径 | 适用场景 |
|---|---|---|
| 需求分析文档 | `docs/FitPulse_需求分析文档.md` | 第一次作业 / 需求分析阶段 |
| 系统设计说明书 | `docs/FitPulse_系统设计说明书.md` | 第二次作业 / 概要设计 |
| 数据库设计说明书 | `docs/FitPulse_数据库设计说明书.md` | 包含 ER 图 + 关系模型 |

**文档已包含**：
- ✅ 标准章节结构（符合 GB/T 8567）
- ✅ Mermaid 格式 ER 图模板
- ✅ ASCII 架构图模板
- ✅ 表格模板（技术栈、开发计划、人员分工）

### B. HTML 原型模板（docs/原型/ 目录）

移动端高保真原型的 HTML 框架：

| 文件 | 说明 |
|---|---|
| `FitPulse_原型.html` | 完整的 7 页移动端原型（390×844px 手机模拟器） |
| `*.png` | 各页面截图 |

**可直接修改**：
- 修改配色（搜索替换 5 个 CSS 变量：`--primary`, `--white`, `--dark`, `--gray-bg`, `--gray-text`）
- 修改页面标题和内容
- 增加/减少页面（复制 `.phone-page` 块即可）

## 📝 模板方法论

本仓库的模板设计遵循以下原则：

1. **填空式设计**：大部分内容保留结构，用 `🔴【待填】` 标记需要替换的内容
2. **国家标准对齐**：文档结构参考 GB/T 8567-2006《计算机软件文档编制规范》
3. **GitHub 原生渲染**：所有文档使用 Markdown + Mermaid，无需额外工具即可在 GitHub 上直接预览
4. **最小安装要求**：原型用纯 HTML/CSS，PDF 转换只需 Pandoc + 已有 Word

## ❓ 常见问题

**Q: 可以直接复制而不是 Fork 吗？**
A: 当然可以！不过 Fork 可以在你的 GitHub 上保留原仓库链接，也方便后续同步模板更新。

**Q: 设计文档中的技术栈可以改吗？**
A: 完全可以！模板只是结构示例。把 FastAPI 改成 Spring Boot、把 React 改成 Vue、把 Claude 改成别的 LLM 都只需要替换关键词。

**Q: 原型 HTML 怎么给别人看？**
A: 用 [htmlpreview.github.io](https://htmlpreview.github.io/) 生成在线预览链接，格式：`https://htmlpreview.github.io/?https://github.com/你的用户名/你的仓库/blob/main/docs/原型/xxx.html`
